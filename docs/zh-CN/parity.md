# 功能状态

以下为 0.4.33 在 Apple Silicon 上的功能及验证范围。适配器自动测试使用预设输入，不代表兼容所有智能体版本或已完成真实模型会话测试。

## 0.4.33 变更

结果回执在发送失败或 worker 退出后保留，且不保存任务文本。辅助请求及未绑定的工具 ID 不会创建任务活动；迟到事件不能重新启动已完成或失败的 Hermes 回合。SSH 来源可区分远程会话与本地跳转失败，提示在三秒后消失。自动测试覆盖重试、进程重启、终态保护、来源归属及提示消失。执行结束不代表任务已验收成功，无法关联的历史事件不会仅凭静默被改为成功。

2026 年 10 月 24 日，使用已安装的 0.4.33（构建 60）和插件 1.14，验证了远程 `backend-coder` 配置的一项真实 API 任务。唯一的 terminal 调用等待 20 秒后返回预期标记，退出码为 0；原生 run 和 admission 均已完成。界面中已目视确认 Working、包含最终回复的 Done，以及 Online / No active tasks。只读状态采样确认完成后空闲且活动任务数为零持续两分钟以上，并收到四次新的在线回执；两个发送队列均为空。本次仅覆盖一个远程 macOS 配置的一项成功 API 任务，未实际触发发送失败、worker 重启、中断或其他入口。

## 0.4.32 变更

旧的未命名空闲会话不再使已确认在线的本地配置旁保留多余的应用行。新的未命名事件，以及独立的工作、等待、审批和失败任务仍分别显示。回归测试覆盖缺失或过期事件、120 秒的有效期边界及任务活动隔离；完整自动测试已通过。本次修正未重复进行手动界面验证。

## 0.4.31 变更

智能体身份区分已确认本地配置、SSH 连接来源与未知来源。应用安装和运行状态只作为后备，不再为活跃本地配置额外创建重复智能体；独立匿名会话保留自己的在线状态。本地安装支持配置选择及准确 home 的启用命令。自动场景覆盖 100 个本地配置、两个各 100 个配置的 SSH 组、900 条任务记录、100 次并发 IPC、来源冲突、连接删除、独立心跳过期及设置/ID 保留。这些是受控输入，不是 300 个真实模型进程。插件 1.13 保持 1.12 事件格式，并加入原生 helper 检查和显式新克隆 ID 操作。原生导出通过全部 79 项检查，并已目视检查含 100 个命名配置的临时目录对应的本地配置选择器。物理键盘、VoiceOver 和数百个真实模型进程仍未验证。


## 0.4.30 新增验证

记忆更新在历史列表、记录详情和当前任务标签中统一使用大脑图标。普通已关闭记录使用归档图标；状态文字和已保存的终态不变。完整测试、发布归档验证和 DMG 检查均已通过。英文、俄文和简体中文的隔离原生历史及记忆卡片检查已通过，并已目视检查列表、详情和 360 pt 窄布局。这些检查使用测试记录，不代表已验证 VoiceOver 或所有受支持 macOS 版本的显示效果。

## 0.4.29 新增验证

Goal 历史可根据明确的目标完成证据，修正跨多个回合恢复执行的原始 `/goal` 记录。只更新已有记录的状态，保留内容和日期，普通取消任务不会被改为完成。回归测试覆盖原生事件、关联工具回执、分块读取、新增归档及不安全文件。对实际本地日志的只读检查找到了目标完成证据，没有修改生产归档。

发布构建通过三种语言的隔离 History/Usage 检查，以及更新安装与损坏归档回滚检查。已检查英文、俄文设置窗口截图；一次 ScreenCaptureKit 临时错误在重试后消失。Clear 测试已修正模拟指针的初始位置，15 项原生交互检查全部通过。

键盘导航仅作用于可见会话，并有回归覆盖。宠物使用原生按钮；登录启动失败不再重复调用服务。实际键盘、VoiceOver 和登录服务错误界面仍需手动验证。

适配器测试覆盖 Hermes 未成功结束的回合、Copilot 事件别名、relay 总超时、对端关闭后的缓冲回执和安全套接字恢复。自定义智能体示例使用隔离套接字测试。本次审计没有修改已安装智能体配置，也没有为每个供应方重新运行完整模型会话。现有远程配置需要单独安装插件 1.12。
